# Подготовка релиза 1.2.0

Состояние на 09.10.2026. Исправления подготовлены поверх `60647e0` и разделены
на отдельные коммиты. Тег и публикация нового релиза не выполнялись.

## Результат исправлений

Устранены дефекты, перечисленные в [ревизии](code-review.md): подтверждение файлов
после сохранения, транзакции SQLite, защита парсеров, обработка ошибок синхронизации,
очередь уведомлений, обмен D-Bus и автоматическая настройка службы.
Добавлен LICENSE; spec и приложение используют версию 1.2.0.

Действующий ключ браслета найден в `[miband8] authKey` файла
`~/.config/ru.nighteugene.aurorafitness/aurorafitness.conf` на устройстве.
Текущая привязка сохранена по указанию пользователя; новый ключ не требуется.
Перед проверками создана резервная копия пользовательских данных на устройстве.

## Выполненные проверки

- `./tests/run.sh`: успешно, Qt 5.6 + UBSan.
- `./tests/release-audit.sh`: все проверки хранилища, парсера, криптографии
  и ActivityFetcher прошли, включая отказ записи, CRC и таймаут без ACK.
- Парсер с UBSan обработал 62 реальных файла сна без ошибок.
- `./build.sh`: успешная сборка aarch64, armv7hl и x86_64; ошибок и
  предупреждений компилятора в журнале нет.
- Все три RPM подписаны сертификатом разработчика: Subject `NightEugene`,
  Group `developer`, Subgroup `regular` проверены через `rpmsign-external dump`.
- Итоговый aarch64 установлен на Fplus MP-67A27 от defaultuser через
  `sdk-deploy-rpm --silent --keepUserData`: Installation successful.
- На Mi Band 8 проверены авторизация, чтение батареи и синхронизация с архивированием.
- Проверены автоматический RestartUnit после обновления, StartUnit при повторном
  открытии и подтверждение запуска через JobRemoved done.
- При удалении приложения работающая служба самостоятельно остановилась и
  удалила собственный юнит; пользовательская БД сохранилась. Пакет установлен снова.
- Итоговая сборка автоматически запустила службу: active/enabled, API ready=true,
  батарея 74%. Повторная авторизация с прежним ключом успешна.
- Страница сна в итоговой сборке отображает график и историю; снимок получен
  через диагностический запуск. Ошибок QML в журнале этого запуска нет.
- Подтверждён обычный запуск GUI под firejail. Таймаут ответа RuntimeManager
  сам по себе не означает, что приложение не запущено.

## Границы проверки

Не выполнены полная перезагрузка телефона, аппаратный прогон PineTime,
визуальное подтверждение всех иконок Mi Band и полный набор сценариев
отзыва разрешений ОС. Эти проверки остаются перед окончательным выпуском.

Валидация профиля regular намеренно отключена (`--novalidate`) по решению
пользователя. README описывает отключение валидации пакетов на устройстве.
Успешная сборка и подпись не означают прохождение валидации профиля.
