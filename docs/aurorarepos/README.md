# Первый выпуск на AuroraRepos

Подготовлен выпуск 1.3.0-1 для профиля «Евгений Тодорук», user_id 75.
Вход в предоставленную учётную запись выполнен, роль `dev` подтверждена.
Карточка и файлы на сайт не загружены. Пароли, токены и cookies в комплект не входят.

## Готовые материалы

- [Описание](description.html) — для HTML-режима редактора описания.
- [Что нового](whats-new.html) — для HTML-режима редактора изменений.
- [Поля карточки](metadata.json) — справочные значения, не запрос к API.
- Комплект файлов: `build-docker-release/aurorarepos-1.3.0/` в корне проекта.
  В нём иконка, 10 скриншотов, тексты и подписанные RPM aarch64/armv7hl.
- x86_64 опубликован в релизе GitHub. В проверенной форме AuroraRepos
  имеются поля для 32- и 64-битного ARM; отдельное поле x86_64 не обнаружено.

## Заполнение формы

1. В [списке приложений](https://aurorarepos.ru/applist) создать «Аврора Фитнес».
2. Добавить версию для «Аврора 5», минимальная версия ОС — 5.2.
3. Выбрать категорию «Здоровье», стабильный канал и бесплатное распространение.
4. Загрузить armv7hl в поле 32-битного RPM, aarch64 — в поле 64-битного RPM.
   Версия и релиз должны определиться как 1.3.0 и 1.
5. Добавить `icon.png`, скриншоты по номерам, описание и текст изменений.
6. Установить флаг «Приложение не проходит валидацию».
   В описании уже указано требование отключить валидацию пакетов на устройстве.
7. Сверить поля и отправить карточку только после отдельного указания пользователя.

Имя разработчика берётся из текущего профиля. Сайт — репозиторий GitHub,
контакт — nighteugene@ya.ru. Возрастной рейтинг, ссылка на политику
конфиденциальности и донаты оставлены незаполненными: решения по этим
необязательным полям не принимались от имени пользователя.

## Проверенные ограничения формы

По публичному клиенту сайта на 09.10.2026: описание до 4000 символов,
«Что нового» до 2000, RPM до 200 000 000 байт, иконка до 1 000 000 байт,
каждый скриншот до 5 МиБ. Подготовленные материалы укладываются в эти ограничения.
Проверка сервером ещё не выполнялась, поскольку загрузки не было.
