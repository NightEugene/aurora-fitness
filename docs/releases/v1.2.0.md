# Аврора Фитнес 1.2.0 — подготовка выпуска

Версия собрана для проверки, тег и публикация пока не созданы.

- Служба настраивается при обычном запуске приложения, результат её запуска
  проверяется через systemd. После удаления приложения служба завершает работу.
- Файлы Mi Band подтверждаются после сохранения; запись статистики атомарна,
  оригиналы сохраняются для восстановления и поддержки новых форматов.
- Исправлены потеря показателей при пустой сводке, запись повреждённых данных
  сна и ложное сообщение об успехе при таймауте/ошибке CRC.
- Исправлены интервалы повторных попыток, очередь уведомлений и отмена ожидающих
  действий после отключения функций. Содержимое уведомлений не попадает в журнал.
- Добавлена защита от устаревших ответов D-Bus и смешивания BLE-пакетов,
  проверяются ошибки OpenSSL и коды завершения CLI.
- Рост и вес находятся в «Профиле». Интервал автосинхронизации настраивается
  в «Настройках»; поле неактивно при выключенной автосинхронизации.
- Исправлено обновление истории батареи; календари доступны для всей сохранённой
  истории, длинный список ночей раскрывается порциями.

Перед установкой отключите валидацию пакетов в настройках режима разработчика.
После установки откройте приложение и подтвердите запрошенные Bluetooth и
«Пользовательские службы». Ручное копирование юнитов не требуется.

Проверки и оставшиеся аппаратные сценарии: [отчёт](../code-review.md).
