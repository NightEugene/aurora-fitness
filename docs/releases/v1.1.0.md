# Аврора Фитнес 1.1.0

Релиз для ОС Аврора 5.2: поддержка PineTime, подробная статистика и обновлённая работа фоновой службы.

## Новое

- PineTime с InfiniTime: шаги, текущий пульс, батарея, уведомления и синхронизация времени; управление MPRIS-плеером с часов. Ключ авторизации не требуется. Калории рассчитываются по шагам и профилю; архив сна и активности для PineTime не поддерживается.
- Дневная статистика с кольцами целей, недельной лентой и шагами по часам. Отдельные страницы метрик и истории батареи, настройка карточек главного экрана.
- Страница сна с фазами, выбором ночи и календарём. Исправлено удвоение фаз при чтении накопительного файла Mi Band 8; ночь относится к дате пробуждения.
- Нативное обновление жестом вниз. Переполнение целей обозначается полукругами по направлению кольца; ползунки сохраняют цели после отпускания, уменьшая задержки интерфейса.

## Исправления

- Фоновая служба постоянно владеет BLE-подключением; интерфейс получает состояние и выполняет команды через D-Bus. Отключение пересылки уведомлений сохраняет работу службы статистики.
- Обложка обновляется после синхронизации. В сведениях об устройстве отображаются батарея, версия прошивки и BLE-сервисы. Подписи дат на графике батареи учитывают ширину текста.
- Иконки уведомлений выбираются по приложению-источнику; ограничена повторная загрузка в небольшое хранилище Mi Band.
- Добавлены проверки повреждённых protobuf, параметров шифрования и путей кэша иконок; исправлены отдельные утечки и чтение устаревших целей в службе.
- Обновлены инструкции установки, архитектуры и регрессионных проверок.

## Установка и обновление

Выберите RPM для архитектуры устройства: `aarch64` (включая Fplus MP-67A27), `armv7hl` или `x86_64`. Устанавливайте пакет от `defaultuser`.

После первой установки выполните в SSH-сеансе `defaultuser`:

```sh
mkdir -p ~/.config/systemd/user
cp /usr/share/ru.nighteugene.aurorafitness/ru.nighteugene.aurorafitness-daemon.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now ru.nighteugene.aurorafitness-daemon
```

После обновления:

```sh
systemctl --user restart ru.nighteugene.aurorafitness-daemon
```

## Известные ограничения

- При сбое записи в SQLite файл активности Mi Band может быть подтверждён до успешного сохранения. Резервное копирование локальной базы рекомендуется до обновления.
- При пропуске файлов по таймауту или ошибке CRC синхронизация может сообщить об успешном обновлении неполных данных.
- Во время отсутствия подключения очередь уведомлений сохраняет только последнее ожидающее сообщение.
- Визуальное отображение всех иконок уведомлений на Mi Band требует дополнительной проверки.

Подробности ревизии: [docs/code-review.md](https://github.com/NightEugene/aurora-fitness/blob/v1.1.0/docs/code-review.md).

## Проверки

Регрессионные тесты protobuf, AES-CCM и путей иконок прошли с UBSan. RPM собраны и проверены валидатором SDK для трёх архитектур. На Fplus MP-67A27 установлен пакет aarch64, после перезапуска служба подключилась к Mi Band 8 и вернула заряд 26% и прошивку 2.3.14 через D-Bus.
