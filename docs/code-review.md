# Исправления по ревизии — 09.10.2026

Подготовлена проверочная версия **1.2.0**. Дефекты исходников из ревизии
исправлены; изменения пока не закоммичены. Исходные выводы сохранены в
[отчёте до исправлений](code-review-2026-10-09.md).

## Сохранность данных

- `Storage::saveParsed` возвращает результат общей транзакции. Ошибка любого
  запроса или COMMIT отменяет запись целого файла; GUI получает dataChanged
  после успешного COMMIT. Пустая дневная сводка не меняет существующие показатели.
- `ActivityFetcher` подтверждает файл только после успешного обработчика
  сохранения. Storage сначала атомарно сохраняет оригинал в
  `~/.config/ru.nighteugene.aurorafitness/activity/<устройство>/`.
  Идентификатор файла и SHA-256 содержимого в имени сохраняют разные снимки;
  повторная загрузка того же содержимого не создаёт второй архив.
- Неизвестный/повреждённый формат сохраняется только как оригинал, без изменения
  статистики. После подтверждённого архивирования его можно убрать из очереди
  браслета, но вся синхронизация отмечается как неполная; время успеха не меняется.
  При ошибке архива или БД подтверждение не отправляется.
- Парсер сна проверяет усечение блоков и записей; чтение big-endian выполняется
  в явно заданном порядке. Неполный снимок без фаз не удаляет уже известные фазы.
- SQLite использует user_version=1, проверяемую транзакционную миграцию,
  индекс фаз сна и таймаут ожидания блокировки. GUI не повторяет DELETE/UPDATE
  миграции при каждом открытии базы. Компоненты пути БД проверяются.

## Синхронизация, уведомления и связь

- CRC, таймауты, отказ сохранения и повреждённый список файлов дают неполный
  результат, а не «Данные обновлены». Повторный запрос не сбрасывает текущую выгрузку.
- Время попытки и время последнего успеха разделены. Успех хранится отдельно
  для каждого адреса браслета; старое значение переносится однократно.
  Интервал в демоне ограничен 1–1440 минутами.
- Очередь уведомлений хранит до 20 сообщений с возрастом не более пяти минут;
  при переполнении удаляется самое старое. Сообщения передаются по одному
  с интервалом в секунду. Отключение пересылки или смена устройства очищает очередь;
  отключение автосинхронизации отменяет ожидающую попытку.
- Заголовок и тело уведомления больше не пишутся в обычный журнал.
- Запросы BandProxy привязаны к поколению владельца D-Bus-имени; учитывается
  прямая смена владельца и новое состояние, пришедшее во время getState.
  Ошибки команд передаются GUI. Старые Connect-ответы BlueZ игнорируются.
- При потере службы очищаются сведения о соединении, сканировании, сервисах
  и результатах. D-Bus передаёт samplesCount/stagesCount вместо массивов нулей.
- RX-состояние Xiaomi раздельное для каждой характеристики, с ограничением
  размера, количества частей и времени ожидания. Все результаты EVP проверяются;
  DataUpload и подтверждение аутентификации прекращаются при ошибке шифрования.

## Служба, CLI и интерфейс

- GUI подписывается на JobRemoved до StartUnit/RestartUnit. Ревизия сохраняется
  только после результата done; предусмотрены ранний сигнал, отказ и таймаут.
  Ошибка чтения бинаря при вычислении хеша тоже обрабатывается.
- После удаления приложения демон замечает отсутствие бинаря, ждёт 30 секунд
  (чтобы пережить переустановку), отключает собственный автозапуск, удаляет свой
  скопированный юнит и завершает работу. Пользовательские данные не удаляются.
- CLI прекращает работу без владения браслетом. Ошибка возвращает код 1,
  таймаут — 2; длительность сканирования проверяется.
- Заряд 0% сохраняется; новое показание уведомляет открытый график батареи.
- Границы дня в MetricPage вычисляются календарно, с учётом дней разной длины.
  Календари видят всю сохранённую историю. Список ночей загружается порциями
  по кнопке «Показать ещё»; при обновлении сохраняется выбранная ночь.
- Добавлен BSD-3-Clause LICENSE в репозиторий и RPM. Spec и версия приложения —
  1.2.0, экран «О приложении» читает версию приложения.

- `./tests/release-audit.sh`: сохранение сводок, откат сна, ошибка OpenSSL,

- Тест ActivityFetcher: успешное сохранение перед ACK, отказ хранилища,

- RPM собраны для aarch64, armv7hl и x86_64 без ошибок и предупреждений компилятора,
  подписаны сертификатом NightEugene. Пакет aarch64 установлен с сохранением данных.

  На устройстве подтверждены JobRemoved done, автоматический RestartUnit после
  обновления и StartUnit без перезапуска при повторном открытии.
- Диагностические снимки главного экрана и страницы сна получены на устройстве.
  Обычный GUI также запущен через RuntimeManager под firejail; ответ самого
  InvokeIntent может завершаться таймаутом, поэтому проверялся процесс приложения.

## Что требует отдельных действий

- Действующий ключ проверен в настройках на устройстве: он сохранён, авторизация
  и синхронизация работают. По указанию пользователя текущая привязка сохранена;
  новый ключ и перепривязка не требуются. История git не переписывалась.
- Проверка после полной перезагрузки телефона, аппаратный прогон PineTime и
  визуальное подтверждение всех иконок Mi Band не выполнены. Это границы проверки,
  а не подтверждение работоспособности этих сценариев.
- Проверка профиля regular намеренно отключена по принятому решению пользователя.
  Сборка и подпись не означают прохождение этой валидации.
